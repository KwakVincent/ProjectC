01 / 훈련모드 화면 예제

직접 배치하고, 말로 설명하고, 움직임을 시험한다

훈련모드는 훈련소에서 새 액션을 생성하는 활동이다. 기준물을 직접 배치하고 음성으로 설명해 로봇의 움직임을 확인한 뒤 액션을 등록한다.

02 / 액션 생성 구조

목소리와 환경으로 액션을 만든다

훈련소에서는 액션을 만들고 로봇을 직접 움직여 시험한다. 평가와 발전은 스테이지에서 쌓은 기록으로 진행한다.

TRAINING GROUND

새로운 액션을
내 로봇의 것으로

플레이어가 적을 나타내는 소품, 장애물, 도로 등을 훈련소에 끌어다 배치한다. 이어서 배치한 오브젝트를 말로 지칭하며 새 액션의 명령어와 로봇이 어떻게 움직여야 하는지 설명하면, 파트너 조력자인 천재 기술자 ‘을지 원(수석 엔지니어)’이 훈련 환경 제어와 동작 시험 및 액션 등록 과정을 서포트한다. 이 말은 액션별 텍스트 정보로 등록해 이후 발화와 비교할 기준으로 사용한다.

기본 동작 01

사방향 단위 이동

전진·후진·좌·우를 기본 단위 이동으로 사용한다. 이동 방향은 카메라 시야의 수평 방향을 실시간으로 추적한다. “앞으로 가” 실행 중 플레이어가 카메라(에임)를 회전하면 로봇의 전진 방향도 회전한 시야의 수평 정면을 따라 실시간으로 바뀐다.

기본 동작 02

기준 오브젝트에 대한 이동

언리얼 시스템이 에임 타겟 기준으로 식별한 적·장애물·도로에 맞춰 목표 위치나 방향을 정한다. 필요한 경로는 내비게이션 메시로 계산하고 단위 이동으로 실행한다. 실전에서 계산된 목표 위치가 장애물 내부이거나 이동 불가 구역(내비게이션 메시 외부)일 경우, 해당 목표 지점에서 가장 가까운 이동 가능 위치로 자동 보정하여 이동한다.

‘타겟의 정면’처럼 대상과 상대 위치를 설명할 기준이 된다.

장애물

막힌 공간과 돌아가는 움직임을 설명할 기준이 된다.

도로

따라가거나 벗어나는 경로를 설명할 기준이 된다.

훈련모드 상세 규칙 / 01 · 기준물 배치

훈련할 상황을 직접 만든다

같은 종류의 기준물을 여러 개 배치할 수 있다. 기준 대상은 임의의 생성 이름 대신 훈련소와 실전 모두 명시적으로 ‘타겟’이라 지칭하며, 장애물·도로 등 일반 오브젝트는 고정된 분류 명칭(‘장애물’, ‘도로’ 등)을 사용하고 에임 타겟 기준 상대 방향과 거리로 특정하는 것으로 확정한다.

기능 보고서

기능규칙·제안이유
기준물 추가목록에서 가상의 적·장애물·도로를 골라 훈련 공간의 바닥에 끌어다 놓는다.이동을 설명할 대상과 주변 환경을 플레이어가 직접 구성한다.
복수 배치 · 확정가상의 적·장애물·도로는 같은 종류도 여러 개 배치할 수 있다.적 여럿과 여러 장애물·도로가 있는 이동 상황도 구성할 수 있다.
명시적 타겟 및 고정 명칭 · 확정기준 대상은 별도 생성 이름 없이 명시적으로 ‘타겟’이라 부른다. 장애물·도로 등 일반 오브젝트는 이미 정해진 고정 분류 명칭(‘장애물’, ‘도로’ 등)을 사용하며, 에임 타겟을 기준으로 한 상대 방향(예: ‘타겟 기준 오른쪽 도로’)에서 가장 가까운 오브젝트를 계산해 추출한다.훈련소와 실전의 지칭 체계를 ‘에임 타겟’ 중심으로 통일하고, 복수 오브젝트 중 목표를 직관적으로 특정한다.
기준물 선택배치한 기준물을 선택하면 강조 표시하고 위치·회전 조작을 보여준다.지금 수정하고 있는 대상을 분명하게 확인한다.
위치 이동선택한 기준물의 위치를 바꾼다.대상까지의 거리와 장애물 배치를 바꾸어 다른 이동 상황을 만든다.
방향 회전선택한 기준물의 방향을 바꾼다. 가상의 적은 정면 방향을 눈으로 확인할 수 있게 표시한다.적의 ‘정면·후면’은 적의 시선 방향에 따라 달라지므로 위치와 방향을 구분해야 한다.
선택 삭제선택한 기준물만 삭제한다.훈련 환경 전체를 다시 만들지 않고 필요한 부분을 수정한다.
배치 초기화훈련 공간에 배치한 기준물을 모두 제거한다. 이미 등록한 액션과 기존 성장 기록은 유지한다.현재 환경을 지우는 동작과 누적한 로봇의 성장을 지우는 동작을 구분한다.

흐름 보고서

기준물 종류 선택 → 바닥에 복수 배치 → 대상 선택과 위치·방향 수정 → 에임 타겟 지정 → ‘타겟’ 및 타겟 기준 방향의 고정 오브젝트 명칭(‘오른쪽 도로’, ‘왼쪽 장애물’ 등)으로 음성 설명.

지칭 예시: ‘타겟의 정면 3m까지만 가’, ‘타겟 오른쪽 도로로 이동해’. 모든 공간 기준은 에임에 타겟팅된 대상을 원점으로 삼으며, 주변 오브젝트 탐색은 플레이어가 타겟을 바라보는 시선 방향을 기준으로 계산한다.

훈련모드 상세 규칙 / 02 · 음성 설명

말로 설명한 움직임을 확인하고 시험한다

호출 명령과 움직임 설명은 각각 입력하는 것으로 확정한다. 적·장애물·도로 등 모든 기준 오브젝트는 에임에 타겟팅된 대상을 기준으로 실행하는 대원칙을 따른다. 적과 일반 오브젝트의 LockOn(대상 고정) 방식 및 방향 계산 기준을 아래와 같이 확정한다.

기능 보고서

기능규칙 초안이유
호출 명령 입력 · 확정앞으로 이 액션을 부를 때 쓸 표현을 입력한다. 예: ‘정면으로 접근해’. 액션 이름과 호출 표현은 별개로 다룬다.액션을 부르는 말과 움직임을 가르치는 설명은 역할이 다르다.
움직임 설명 입력 · 확정호출 명령과 별도의 음성 입력으로 원하는 동작을 설명한다. 예: ‘타겟의 정면 3m 지점으로 가서 멈춰’, ‘타겟 오른쪽 도로로 빠져’.짧은 호출 명령에 대상·방향·거리·정지 조건을 모두 담지 않아도 된다.
에임 타겟 대원칙 및 방향 기준 · 확정모든 액션의 기준은 카메라 에임에 타겟팅된 대상을 기준으로 한다. 적 자체의 정면·후면은 적의 시선 방향을 따르고, 장애물의 앞·뒤·좌·우 및 타겟 기준 주변 오브젝트(‘오른쪽 도로’, ‘왼쪽 장애물’ 등) 탐색 방향은 플레이어(카메라)가 타겟을 바라보는 시선 방향을 기준으로 계산해 가장 가까운 해당 오브젝트를 선택한다.훈련과 실전의 기준점을 ‘에임 타겟’으로 일원화하고, 정면이 없는 일반 오브젝트나 좌우 탐색에서 플레이어가 보는 화면 방향과 실제 이동 방향을 일치시킨다.
적 자동 록온 및 전환 · 확정에임에 타겟팅된 적은 카메라 시야(화면)에서 완전히 벗어나기 전까지 자동으로 록온(대상 고정)된다. 시야를 완전히 다른 곳으로 돌려 적이 화면 밖으로 벗어나면 해제된다. 화면 안에 여러 적이 있을 때 에임 중심으로 다른 적을 직접 가리키면 새 적으로 타겟을 즉시 바꾸며, 록온 버튼을 누르고 있는 동안에만 다른 적을 스쳐도 기존 적을 유지한다.교전 중 조준이 흔들려도 적 타겟이 쉽게 풀리지 않게 하면서, 다른 적을 직접 조준할 때는 즉각 타겟을 바꿀 수 있게 한다.
일반 오브젝트 홀드 록온 · 확정장애물·도로 등 일반 오브젝트는 록온 버튼을 누르고 있을 때(Hold)에만 고정하고, 버튼을 누르지 않은 상태에서는 에임 밖으로 나가면 즉각 타겟팅을 해제한다.전장에 많은 일반 오브젝트가 에임에 불필요하게 계속 고정되는 일을 막고, 플레이어가 의도할 때만 고정한다.
타겟 소실 및 목표 보정 · 확정이동 중 타겟을 잃어도 이동을 중단하지 않고 마지막으로 계산한 목표 위치까지 이동한다. 실전에서 계산된 목표 위치가 장애물 내부나 이동 불가 구역(내비게이션 메시 외부)이면 해당 지점에서 가장 가까운 이동 가능 위치로 자동 보정해 이동한다.대상이 해제되거나 목표 지점이 벽·지형에 막혀 있어도 이동이 멈추지 않고 가장 가까운 유효 지점까지 안전하게 기동한다.
인식 문장 표시음성에서 인식한 문장을 화면에 보여준다. 잘못 인식된 경우 다시 말하거나 표시된 문장을 수정한다.음성 인식 오류와 이동 조건 해석 오류를 구분할 수 있다.
이동 조건 표시해석한 대상·방향·거리·정지 조건을 인식 문장과 함께 보여준다. 기본 사방향 이동은 카메라 수평 방향을 실시간으로 추적한다.시스템이 어떤 움직임을 구성했는지 플레이어가 시험 전에 확인한다.
대상 확인에임 타겟과 타겟 기준으로 탐색된 주변 오브젝트(‘장애물’, ‘도로’ 등)를 강조 표시한다. 조건에 맞는 대상을 찾지 못하면 보완하도록 안내한다.의도하지 않은 오브젝트를 기준으로 움직임을 만드는 일을 줄인다.
불명확한 조건 보완시험에 필요한 조건이 빠지거나 여러 해석이 가능하면 해당 부분을 묻고 보완한다. ‘3m까지만 가’의 3m가 이동량인지 타겟과의 거리인지 불명확하면 확인한다.같은 거리 표현이라도 시작점과 기준점에 따라 다른 움직임이 된다.
동작 시험으로 전달호출 표현과 이동 조건이 준비되면 동작 시험을 사용할 수 있다. 플레이어가 표시된 내용을 확인하고 시험을 시작한다.말로 만든 동작을 직접 실행해 확인할 수 있게 흐름을 이어 준다.

흐름 보고서

호출 명령 입력 → 에임 타겟 기준으로 움직임을 음성 설명 → 인식 문장과 이동 조건·탐색 대상 표시 → 불명확한 부분 보완 → 플레이어가 동작 시험 시작.

설명 예시

“타겟의 정면 3m 지점으로 가서 멈춰.”

훈련과 실전 모두 에임에 타겟팅된 대상의 정면 방향 3m 지점으로 이동해 멈춘다. ‘타겟 오른쪽 도로로 가’처럼 말하면 플레이어 시선 기준 타겟의 오른쪽 방향에서 가장 가까운 도로 오브젝트를 찾아 이동한다.

대원칙: 모든 기준물(적·장애물·도로)은 에임 타겟을 기준으로 작동한다. 적은 시야 이탈 전까지 자동 록온(다른 적 직접 조준 시 전환), 일반 오브젝트는 록온 버튼 홀드 시에만 고정하며 에임 이탈 시 즉각 해제한다.

이동 중 타겟을 잃은 경우에는 마지막으로 계산한 목표 위치까지 이동하는 것으로 확정한다.

훈련모드 상세 규칙 / 03 · 동작 시험

로봇을 움직여 확인하고, 수정해 다시 시험한다

첫 시험의 시작 위치·방향과 카메라 수평 방향을 기록하고, 재시험마다 복원하는 것으로 확정한다. 훈련소 동작 시험의 성공·실패 유무는 시스템이 강제 판정하지 않고 플레이어(유저)가 직접 보고 판단하는 것으로 확정한다. 시험은 구성한 액션의 움직임을 확인하는 과정이며, 칭찬·비난에 따른 선택 확률과 성장값 조정은 기존 기획대로 전투 스테이지 종료 시에 진행한다.

기능 보고서

기능규칙 초안이유
시작 준비설명에서 만든 이동 조건과 필요한 기준물을 확인한다. 필요한 대상이나 조건이 준비되지 않으면 실행하지 않고 보완할 부분을 표시한다.실행할 수 없는 설명을 정상 시험처럼 시작하지 않는다.
시작 기준 기록 · 확정첫 시험을 시작할 때 로봇의 위치·방향과 기본 사방향 이동의 기준인 카메라 수평 방향을 기록한다.설명을 수정한 효과를 같은 시작 조건에서 비교할 수 있다.
시험 시작동작 시험을 누르면 현재 구성한 액션을 실행한다. 대상·계산한 목표 위치·이동 경로와 실행 상태를 화면에 보여준다.플레이어가 설명한 동작과 실제 움직임을 비교한다.
시험 중단시험 중에는 중단 버튼을 제공한다. 누르면 해당 시험의 이동 실행을 취소하고 로봇은 그 위치에서 멈춘다. 작성한 설명과 기준물 배치는 유지한다.의도와 다른 동작이나 지속형 이동을 원하는 시점에 멈추고 확인·수정할 수 있다.
유저 판단 확인 · 확정훈련소에서 동작의 성공·실패(의도에 맞는지 여부)는 시스템이 판정하지 않고 플레이어가 직접 판단한다. 지속형 이동을 포함해 시스템의 완료 판정에 묶이지 않고 플레이어가 결과를 확인해 등록 또는 재수정 여부를 결정한다.플레이어가 의도한 움직임인지 여부는 플레이어 자신이 가장 정확하게 판단할 수 있다.
실행 불가목표로 갈 경로를 만들 수 없으면 이동을 실행하지 않거나 중단하고 이유를 표시한다. 임의의 가까운 위치를 정상 도착으로 처리하지 않는 안을 제안한다.실행할 수 없는 상황과 설명이 의도와 다른 상황을 구분한다.
조건 수정시험 확인·중단 후에 배치와 음성 설명을 수정한다. 실행 중 수정하려면 먼저 시험을 중단하는 안을 제안한다.한 번의 시험 안에서 조건이 섞이지 않도록 한다.
재시험 · 확정기록한 시작 위치·방향과 카메라 수평 방향으로 시험 시작 조건을 복원한 뒤 수정된 액션을 실행한다. 현재의 기준물 배치와 설명은 유지하고 목표 위치·경로는 새로 계산한다.시작 조건은 맞추고 플레이어가 수정한 내용은 유지해 결과를 비교한다. 배치 초기화와 구분한다.

흐름 보고서

이동 조건 확인 → 시작 기준 기록 → 시험 시작 → 플레이어가 움직임 확인(또는 수동 중단) → 필요 시 배치·설명 수정 및 시작 조건 복원 후 재시험 → 플레이어 판단에 따라 액션 등록 단계로 이동.

훈련소의 성공·실패 유무는 플레이어가 판단하므로 시스템의 시험 완료 판정이 액션 등록을 가로막지 않는다. 시험 중 기준 대상을 잃는 경우는 확정한 마지막 목표 위치 유지 규칙과 일관되게 처리한다.

훈련모드 상세 규칙 / 04 · 액션 등록·수정·삭제

시험한 움직임을 저장하고 관리한다

기존 액션은 유지한 채 임시본에서 수정하고, 저장할 때만 기존 액션을 갱신한다. 취소하면 임시 변경을 버리고 기존 액션을 유지한다. 훈련소 시험의 성공·실패는 플레이어가 직접 판단하므로 플레이어가 확인 후 언제든 등록·저장할 수 있다. 액션 이름은 고유해야 하며, 동일한 호출 명령뿐 아니라 RoBERTa(Robustly Optimized BERT Pretraining Approach) 임베딩 유사도가 임계치 이상인 유사 호출 명령도 중복 등록할 수 없는 것으로 확정한다.

기능 보고서

기능규칙 초안이유
등록 정보액션 식별 정보·표시 이름·호출 표현·움직임 설명 텍스트·정리한 이동 조건을 저장한다. 대상·상대 방향·거리·종료 조건은 해당 액션에 필요한 항목을 저장한다.액션을 구분하는 정보, 음성 선택에 쓸 텍스트, 실행할 동작을 함께 유지한다.
실전 기준 저장 · 확정모든 기준물 동작은 실전 에임 타겟과 타겟 기준 상대 탐색 규칙에 연결한다. 훈련에서 계산한 절대 목표 위치와 경로를 실전의 고정 목표로 저장하지 않는다.전투의 에임 타겟 위치·방향과 록온 상태에 맞춰 목표와 경로를 실시간으로 다시 계산해야 한다.
신규 등록 · 확정필요한 정보가 갖춰지면 플레이어가 동작을 판단해 등록할 수 있다. 등록을 선택하면 이름·호출 명령의 중복 및 의미 유사도 여부를 확인한 뒤 저장하고, 목록과 이후 음성 선택 후보에 포함한다.성공·실패 판단을 플레이어에게 맡기고, 중복 검사 통과 시 즉시 후보에 반영한다.
이름·유사 호출 명령 중복 금지 · 확정액션 이름은 등록된 액션 목록에서 고유해야 한다. 동일한 호출 명령뿐 아니라 기존 등록된 호출 명령과 RoBERTa 문장 임베딩 유사도가 임계치 이상인 유사 표현도 다른 액션에 등록할 수 없다. 신규 등록과 수정 저장 전에 중복·유사도를 확인하고, 걸리면 저장을 막고 변경을 안내한다.글자만 조금 다른 유사 호출 명령이 등록되어 실전에서 인공지능 분류기가 혼동하는 일을 원천 차단한다.
수정 시작 · 확정기존 액션을 수정할 때 시험용 임시본을 만든다. 저장하기 전까지 등록된 기존 액션을 유지한다.수정 도중의 미완성 동작이 기존 액션을 바꾸지 않도록 한다.
수정 저장 · 확정수정한 내용은 플레이어가 직접 판단해 저장할 수 있으며, 저장 전에 이름·호출 명령 중복 및 유사도 검사를 진행한다. 저장하면 기존 액션을 갱신하고, 취소하면 임시 변경을 버리고 기존 액션을 유지한다.플레이어의 판단에 따라 유연하게 수정·저장하되 호출 명령 충돌은 엄격히 방지한다.
액션 삭제삭제할 액션 이름과 호출 표현을 보여주고 삭제 여부를 확인한다. 삭제하면 그 액션을 등록 목록과 음성 선택 후보에서 제외한다. 다른 액션과 로봇 전체 성장값은 삭제하지 않는 안을 제안한다.실수로 다른 액션을 지우는 일을 줄이고, 개별 액션 관리와 전체 성장 초기화를 구분한다.

흐름 보고서

신규: 액션 구성 및 플레이어 확인 → 등록 선택 → 이름·호출 명령 중복 및 임베딩 유사도 확인 → 정보 저장 → 등록 목록·음성 선택 후보 반영.

수정: 기존 액션 선택 → 임시본 수정 및 플레이어 확인 → 이름·호출 명령 중복 및 임베딩 유사도 확인 → 저장 시 기존 액션 갱신 / 취소 시 기존 액션 유지.

삭제: 기존 액션 선택 → 삭제할 액션 확인 → 목록과 음성 선택 후보에서 제외.

수정·삭제 시 평가 기록과 선택 확률의 확정 처리 규칙은 아래에 정리한다. 노심 교체 시 기존 등록 액션과 훈련 결과를 유지한다는 확정 규칙은 그대로 적용한다.

훈련모드 상세 규칙 / 05 · 수정·삭제 시 평가 처리

호출 명령이나 이동 조건을 바꾸면 평가 조정분을 초기화한다

액션 표시 이름만 바꿀 때는 기존 평가에 따른 선택 확률 조정분을 유지한다. 반면 호출 명령을 바꾸거나 이동 조건(실제 동작)을 수정하면 다른 명령·다른 움직임이 된 것이므로 선택 확률 조정분을 초기 상태로 리셋하는 것으로 확정한다. 과거 평가 기록 이력과 다른 액션·로봇 전체 성장값은 유지한다.

기능 보고서

변경 종류처리 규칙이유
액션 이름만 변경 · 확정호출 명령과 이동 조건이 같으면 기존 평가 기록과 선택 확률 조정분을 유지한다.단순 표시 이름 변경은 실제 음성 호출이나 움직임에 영향을 주지 않는다.
호출 명령 변경 · 확정이전 명령의 평가 기록은 당시 실제 발화와 발동 액션에 연결한 상태로 보존한다. 새 호출 명령에는 이전 명령의 평가 조정분을 적용하지 않고 초기 상태로 리셋한다.평가는 호출 명령에 대해 이루어지므로 명령을 바꾸면 조정분을 초기화한다. 선택 확률 자체를 0으로 만든다는 뜻은 아니다.
이동 조건 변경 · 확정호출 명령이 같더라도 이동 조건(실제 동작)을 수정하면 과거 평가 기록은 이력으로 보존하되, 선택 확률 조정분은 초기 상태로 리셋한다.잘못 만든 동작을 수정했는데 과거의 비난 패널티가 남거나, 전혀 다른 동작에 과거 평가 가중치가 그대로 유지되는 모순을 막는다.
수정 취소 · 확정임시 변경을 버리고 기존 액션과 평가 기록·선택 확률을 그대로 유지한다.저장하지 않은 변경으로 기존 성장 결과가 달라지지 않게 한다.
액션 삭제삭제한 액션은 선택 후보에서 제외하되 과거 전투의 평가 기록은 이력으로 남기는 안을 제안한다. 그 기록을 다른 액션으로 옮기지 않고, 다른 액션과 로봇 전체 성장값은 유지한다.어떤 명령에서 어떤 동작을 평가했는지 보존하고 평가 대상을 임의로 바꾸지 않는다.

흐름 보고서

임시본 수정 → 저장 선택 → 이름·호출 표현·이동 조건 중 변경 항목 확인 → 호출 명령 또는 이동 조건 변경 시 선택 확률 조정분 초기화(이름만 변경 시 유지) → 액션 갱신.

함께 결정할 항목은 초기 선택 확률의 계산식과 삭제 시 평가 기록 보존·같은 이름으로 재등록할 때의 처리다. 노심 교체 시에는 기존 액션·훈련 결과 유지 규칙을 따른다.

훈련 예시

“타겟의 정면 3m까지만 가!”

훈련소와 실전 모두 에임에 타겟팅된 대상을 ‘타겟’으로 지칭한다. 이 예시는 타겟의 정면 방향, 3m 거리, 멈출 조건을 설명한다. 장애물과 도로는 고정 명칭을 사용하며, ‘타겟 오른쪽 도로’처럼 플레이어 시선 기준 타겟의 상대 방향에서 가장 가까운 오브젝트를 찾아 이동 환경을 구성한다.

현재 코드와 목표의 구분 · 기본 명령에는 전·후·좌·우 방향 매핑이 있다. 실제 이동은 카메라 시야와 연결된 제어 회전의 수평 방향을 실시간으로 추적해 계산하며, 이 기준을 유지한다. 현재 적 탐지는 액터 태그를 확인하고, 적 접근은 내비게이션 메시로 경로를 계산한 뒤 경로 방향을 전·후·좌·우 이동 입력으로 바꾼다. 플레이어가 배치한 훈련소 기준물과 음성 설명의 연결, 이를 이용한 일반 액션 구성은 기획 목표다.
